  • Experiment 2 · November 2026 · 131,939 answers scored

    Count your tasks before you buy a GPU.

    One RTX 5090 loaded until users would start to wait, every answer scored, the same work priced at a German cloud. Owning beats the API from about 2,850 agent questions a working day, 7,500 once staff time is counted.

  • Experiment 1 · November 2026 · 2,540 answers scored

    More thinking costs more tokens, not always more accuracy.

    Four open models on one RTX 5090, thinking off and on, a single answer and an agent. Thinking multiplied tokens per task up to 6.8 times, while accuracy moved by −20 to +14 points.
